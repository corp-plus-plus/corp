## 🗂️ Keyword Reference

| Keyword | Purpose | Code Example |
|---|---|---|
| `sync_alignment` | Main program block | `sync_alignment { ... }` |
| `quarterly_deliverables` | Namespace / module | `quarterly_deliverables Finance { ... }` |
| `hard_stop` | Process exit | `hard_stop;` or `hard_stop 1;` |
| `action_item` | Mutable variable | `action_item x = 10;` |
| `core_competency` | Immutable constant | `core_competency MAX = 100;` |
| `restructure` | Variable mutation | `restructure x = 20;` |
| `promote` | Unary increment | `promote x;` |
| `demote` | Unary decrement | `demote x;` |
| `layoffs` | Scope memory GC | `layoffs;` |
| `as_per_our_discussion` | If condition | `as_per_our_discussion (x > 0) { ... }` |
| `pivot` | Else condition | `pivot { ... }` |
| `circle_back` | While loop | `circle_back (x < 10) { ... }` |
| `touch_every_base` | For..in loop | `touch_every_base (x in list) { ... }` |
| `table_this` | Break loop | `table_this;` |
| `push_to_next_sprint` | Continue loop | `push_to_next_sprint;` |
| `touch_base` | Print to stdout | `touch_base("Result:", x);` |
| `please_advise` | Prompt stdin | `action_item in = please_advise("Prompt:");` |
| `broadcast_all_hands` | Stderr alert | `broadcast_all_hands("Alert!");` |
| `delegate` | Declare function | `delegate calculate(a, b) { ... }` |
| `loop_in` | Call function | `action_item y = loop_in(calculate(1, 2));` |
| `deliverable` | Return value | `deliverable a + b;` |
| `let's_take_this_offline` | Try block | `let's_take_this_offline { ... }` |
| `mitigate_risk` | Catch block | `mitigate_risk (err) { ... }` |
| `opt_out` | Throw exception | `opt_out "Error message";` |

## 🔣 Operators & Literals

| Symbol / Literal | Meaning |
|---|---|
| `aligned` / `true` | Boolean True |
| `misaligned` / `false` | Boolean False |
| `out_of_office` / `null` | Null Value |
| `synergizes_with` / `&&` | Logical AND |
| `or` / `||` | Logical OR |
| `not` / `!` | Logical NOT |
| `+`, `-`, `*`, `/`, `%` | Arithmetic Operators |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | Comparison Operators |
